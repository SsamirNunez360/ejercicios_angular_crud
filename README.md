# Ejercicios Angular CRUD

Este repositorio contiene varios ejercicios de Angular CRUD organizados por proyecto:

- `biblioteca`
- `estudiantes`
- `tareas`
- `tienda`
- `veterinaria`

## Requisitos

- Node.js
- npm

## Instalación

Entrar a cada proyecto y ejecutar:

```bash
npm install
npm start
```

## Estructura

Cada carpeta es una aplicación independiente con su propio `package.json`, dependencias y configuración de Angular.

## Estado

Este repositorio está configurado como un proyecto inicial para desarrollo y versionado con Git.
